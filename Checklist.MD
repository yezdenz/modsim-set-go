# Preserve supplied checklists

Keep a supplied checklist's original wording, order, formatting, file location, and controls. Do not replace it with an agent-created version or add rows, comments, dates, evidence columns, signatures, or new requirements unless the user expressly requests that change.

Change only existing completion markers for tasks whose full requirements have been verified. A prepared file, unchecked script, or attractive image is not proof of the required execution. Keep partial or unsupported items unchecked.

Preserve preexisting checked markers, but verify their claims independently. Record uncertainty privately instead of silently rewriting the checklist. Do not fabricate a personal attestation or sign for the student.

Use [Evidence.MD](Evidence.MD)'s separate register for explanations and additional checks. The permissions to add answer or code rows in [Tables.MD](Tables.MD) do not authorize redesigning a supplied checklist.

Inspect the actual final checklist from the delivered file or package. Confirm that all newly checked items have supporting evidence and that only authorized markers changed.
