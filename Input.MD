# Collect the task inputs

Use details already supplied or clearly present in the designated template. Do not ask for them again. Do not copy an identity, professor, date, or course section from an unrelated example.

Typical inputs are the student name, course and section, activity title, professor when required, submission date, model parameters, requested file types, and the exact source template. Record them privately.

For declarations, also collect the AI classification, assigned learning code, prompt parameters, and any required conversation link or record. A learning code belongs in the private declaration, not in a public workflow or sample prompt. Use the date specified by the user rather than automatically replacing it with today's date.

Ask a concise question when a fact is missing and cannot be obtained from an authorized source. Continue work that does not depend on it. Do not invent a signature, course policy, dataset, or claim of student verification.

## Confirm conflicts without rewriting the facts

If the assessment says AI-Integrated and the user asks for AI-Assisted, explain the discrepancy and ask which classification the instructor requires. Do not silently treat a label as proof of permission for a kind of AI assistance.

If the user wants DOCX only but the course requires PDF, create the authorized DOCX and identify the remaining submission-format issue. Ask before replacing the requested deliverable or adding unrequested final formats.

Use [Task-Brief.MD](Task-Brief.MD) as an optional private intake sheet. An empty optional field does not justify blocking the rest of a task.
